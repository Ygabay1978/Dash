Fabric Gateway

A gateway that sits between your apps and AI agents and the AI models, MCP servers and APIs they call. It applies your security rules, routes traffic and keeps an audit trail. You pay per request that passes through it.

ModelRate

Separate contractList rate $200 per 1M requests, lowered by committed annual volume: up to 100M: $200 · 100M to 500M: $180 · 500M to 1B: $160 · 1B to 5B: $140 · 5B+: negotiated. Minimum annual commitment: $20K.

Terms in plain language

TermWhat it means
Agent Stack CreditA prepaid unit worth $1 at list price. One pool can be spent on any eligible product.
API / MCP requestOne call that passes through the gateway. MCP (Model Context Protocol) is the standard that lets AI agents use tools and data.
Committed volumeThe yearly traffic the customer agrees to pay for in advance, in return for a lower rate per request.
OverageUsage above what is already included. Only the overage is billed.
Durable identityAlso called "human identities" in some materials. A permanent identity for a person, service or long-lived agent.
Ephemeral identityA short-lived identity for a single task, free of charge.
Passport ProxyThe component in your cloud that makes the API call for the identity and inserts the real secret at the last moment. Postman is not in the request path.
Control plane and data planeThe control plane is where rules are set and monitored. The data plane is where traffic actually flows. For Fabric, the control plane is in Postman cloud and the data plane can run in Postman cloud or in your own cloud.

Which model fits?

Shared credits fit when

  • You want to start quickly and test before committing to a single product.
  • You plan to use more than one product, and want to move spend between them as adoption changes.
  • Usage is hard to forecast, so paying only for what you use is safer.
  • You want the volume bonus of up to +30% on larger purchases.
  • You prefer one purchase and one contract for everything.

A separate contract fits when

  • A single product has become strategic and you need dedicated support, SLAs or professional services for it.
  • You need Fern Enterprise capabilities such as self-hosting, custom code or multiple repos.
  • You only want one product and a credit pool of $50K or more is more than you need.
  • You want terms negotiated specifically for that product, such as committed-volume tiers for Fabric.

Rule of thumb: start with shared credits. Move a product to its own contract when it becomes critical to the business and needs capabilities or service levels that the shared model does not include.
